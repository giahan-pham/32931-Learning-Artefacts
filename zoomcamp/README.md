# MLOps Zoomcamp 2025 – Homework

Solutions to the [DataTalksClub MLOps Zoomcamp](https://github.com/DataTalksClub/mlops-zoomcamp) homework (modules 1, 2, 3, 5 and 6).
Each module has one notebook with the code and the answer under every question.
Everything runs locally: MLflow writes to SQLite files, and "S3" in Module 6 is Localstack, a fake S3 in Docker.

## Setup

```bash
cd zoomcamp
python3.11 -m venv .venv
.venv/bin/pip install "pandas>=2.2,<3" pyarrow "scikit-learn==1.5.0" mlflow hyperopt prefect \
    s3fs boto3 awscli pytest click jupyter ipykernel "evidently==0.4.33" "psycopg[binary]" requests
```

Open a notebook in VS Code or Jupyter and select the `.venv` kernel. Modules 5 and 6 also need Docker Desktop running.

In the file trees below, **(course)** means the file came with the homework, **(edited)** means a course file I changed, and **(new)** means I created it or it was generated by running the code. Large data and generated files are marked *generated*; they are rebuilt by running the notebook.

## Module 1 – Introduction

**What I did:** loaded the January 2023 Yellow Taxi trips, computed trip duration in minutes, dropped outliers (keeping 1–60 minutes), one-hot encoded the pickup/dropoff location IDs with `DictVectorizer`, trained a linear regression, and evaluated it on February 2023.

**Original files:** `homework.md` and the two Yellow Taxi parquet files.

```
module 1/
├── homework.md                          (course)  the questions
├── homework1.ipynb                      (new)     solution notebook
├── yellow_tripdata_2023-01.parquet      (course)  training data
└── yellow_tripdata_2023-02.parquet      (course)  validation data
```

## Module 2 – Experiment tracking (MLflow)

**What I did:** preprocessed Green Taxi data (Jan/Feb/Mar 2023) with `DictVectorizer`; trained a random forest with MLflow autologging; started a local MLflow tracking server (SQLite backend, `artifacts` folder); tuned hyperparameters with `hyperopt`, logging each trial's params and validation RMSE; then retrained the top 5 runs, scored them on the March test set, and registered the best one in the model registry.

**Original files:** `homework.md`, `requirements.txt`, and the four scripts `preprocess_data.py`, `train.py`, `hpo.py`, `register_model.py`.

```
module_2/
├── homework.md                (course)
├── homework2.ipynb            (new)     runs each script and reads the results from MLflow
├── requirements.txt           (course)
├── preprocess_data.py         (course)  builds the train/val/test sets
├── train.py                   (edited)  added mlflow.sklearn.autolog() and start_run()
├── hpo.py                     (edited)  logs params + rmse for every hyperopt trial
├── register_model.py          (edited)  picks the lowest test RMSE and registers it
├── taxi_data_folder/          (course)  green_tripdata_2023-01/02/03.parquet
├── output/                    (new, generated)  train.pkl, val.pkl, test.pkl, dv.pkl
├── mlflow.db                  (new, generated)  MLflow runs for Q3
└── mlruns/                    (new, generated)  artifacts for Q3
```

The tracking server for Q4–Q6 was started from the `zoomcamp/` folder, so its database and artifacts are `zoomcamp/mlflow.db` and `zoomcamp/mlartifacts/`.

## Module 3 – Orchestration (Prefect + MLflow)

**What I did:** built a training pipeline as Prefect tasks (load → prepare → train → register) on March 2023 Yellow Taxi data, trained a linear regression on the location IDs, logged the model to MLflow (in pickle format so the size matches the homework), and registered it as `yellow-taxi-linreg`. The last cell runs all steps as one Prefect flow.

**Original files:** `homework.md` and the March 2023 parquet file.

```
module 3/

├── mlflow.db                            (new, generated)  runs + model registry
└── mlruns/                              (new, generated)  logged model files
```

## Module 5 – Monitoring (Evidently + PostgreSQL + Grafana)

**What I did:** trained a baseline model on January 2024 Green Taxi data and kept part of it as reference data; added a `ColumnQuantileMetric` (median `fare_amount`) to the Evidently report; computed the metrics for each day of March 2024; stored them in PostgreSQL with a Prefect flow; and built a Grafana dashboard (prediction drift and median fare), saved as JSON so Grafana loads it on startup.

**Original files:** `homework (4).md`, `baseline_model_nyc_taxi_data.ipynb` and the March 2024 parquet file.

## Module 6 – Best practices (testing + Localstack)

**What I did:** refactored `batch.py` into functions (`main`, `read_data`, `prepare_data`, `save_data`) with configurable input/output paths and an optional S3 endpoint; wrote a pytest unit test for `prepare_data`; ran Localstack in Docker as a fake S3; and wrote an integration test that uploads test data, runs `batch.py` against it and checks the predictions. `run.sh` runs the whole integration test in one step.

**Original files:** `homework.md` and the starter `batch.py`, `Dockerfile`, `Pipfile`, `Pipfile.lock` and `model.bin`.

```
module 6/
├── homework.md                          (course)
├── Pipfile, Pipfile.lock                (new)     from `pipenv install --dev pytest`
└── homework/
    ├── homework6.ipynb                  (new)     shows the code and runs each step
    ├── batch.py                         (edited)  refactored for testing
    ├── batch_original.py                (new)     copy of the starter batch.py
    ├── Dockerfile.txt                   (course)
    ├── Pipfile.txt, Pipfile.lock        (course)
    ├── model.bin                        (course)  trained model
    ├── tests/
    │   ├── __init__.py                  (new)
    │   └── test_batch.py                (new)     unit test (Q3)
    ├── docker-compose.yaml              (new)     Localstack with S3 only
    ├── integration_test.py              (new)     integration test (Q5–Q6)
    ├── run.sh                           (new)     starts Localstack, creates the bucket, runs the test, stops it
    └── output/                          (new, generated)  predictions from running batch.py for March 2023
```
